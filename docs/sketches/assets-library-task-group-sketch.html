一键导出约定（建议）

导出范围：当前日期分区下、该任务已收藏到素材库的全部图片（不是任务历史里未收藏的草稿）。
打包方式：浏览器下载一个 ZIP，例如 北美香氛店_香氛主图优化_20260802.zip。
包内命名：01_1158_V3.png / 02_1142_V2.png（序号 + 时间 + 版本）。
可选增强：包内附 meta.txt（任务名、类型、生图人、提示词摘要）；日期级「导出当日全部任务」次要入口。

请确认

  1. 层级是否定为：日期 → 任务包 → 多图？
  2. 任务包外观更倾向 展开型 还是 紧凑型？
  3. 一键导出是否只要 ZIP 图片，还是需要附带 meta 文本？

也可直接回复例如：「展开型 + ZIP（含 meta）+ 叠在 B3 上」。
