# 对话式生图流程与规则设计

## 目标

将商品素材工作台的对话式生图规则固化为可执行流程：产品层保留多轮对话与版本链，模型层保持万相单轮请求；硬规则由前端校验强制执行，软规则通过引导文案与合成提示词前缀落地。

## 整体流程

```text
创建/进入店铺项目
  → 新建或打开对话任务（锁定类型：商品图加工 / 创意生图）
  → 可选：选用模板/提示词 + 填快捷参数
  → 首轮发送（create）
        商品图加工：必须有原图
        创意生图：可纯文本
  → 右侧产出版本/草稿
  → 选草稿 → 显式引用（或默认引用当前选中稿）
  → 补充修改说明后发送（adjust）
  → 循环调整，直到确认成品 → 保存素材库 / 下载 / 保存提示词
```

原则：

1. **产品层多轮，模型层单轮**：每次只向万相提交「本轮合成提示词 + 最多 2 张参考图」。
2. **一个任务一条对话线**：跨任务/跨项目不继承引用与附件。
3. **每轮必须可执行**：有明确文本意图，或合法的图 + 默认意图；引用修改时文本必填。

## 硬规则（代码必须执行）

| ID | 规则 |
| --- | --- |
| H1 | 无项目不可发送，引导创建项目 |
| H2 | 商品图加工首轮无原图/无引用/无历史版本 → 拦截 |
| H3 | 无文本且无图且无引用 → 拦截 |
| H4 | 已引用但无修改说明 → 拦截 |
| H5 | 任务已有结果后禁止切换类型，需新建任务 |
| H6 | 同时只允许一个生成进行中 |
| H7 | 首轮或失败/空闲重开为 `create`；已有成功结果且为调整语义时为 `adjust` |
| H8 | `adjust` 时显式引用优先；否则默认当前选中草稿，再回退原图 |
| H9 | 切换项目/打开任务时清空瞬时引用预览，禁止跨上下文带图 |
| H10 | 一键重试必须复用最近一次有效生成快照（`retrySnapshots` / `lastGenerationInput`） |
| H11 | 高风险文本拦截（违禁/色情/暴力）→ blocked |
| H12 | 引用图必须属于当前任务（原图或本任务版本草稿）；非法则清空并提示重选 |

## 软规则（引导 + 提示词前缀）

| ID | 规则 | 落地 |
| --- | --- | --- |
| S1 | 局部修改：未点名的主体/商品/构图/关键文字默认保留 | `adjust` 轮合成提示词前缀 |
| S2 | 表达约定：保留什么 / 改什么 / 程度 / 约束 / 输出预期 | 欢迎语、新任务提示、引用后提示 |
| S3 | 选用模板不回写原模板；参数在发送前生效 | 既有行为保持，文档标明 |

## 轮次判定

- `create`：无版本，或任务状态为 `failed` / `blocked` / `idle`，且非显式调整路径。
- `adjust`：存在版本，且（显式引用 / 成功后继续发送 / 「引用调整」待发）为真。
- 请求组装：文本来自模板快照 + 快捷参数 + 本轮指令（`adjust` 时加 S1 前缀）；图片为原图与引用图去重后最多 2 张。

## 非目标

- 不向万相伪造完整多轮聊天历史。
- 不扩大内容安全词库。
- 不重写对话状态机为独立引擎。
- 本次不改服务端万相调用协议。

## 验收

1. 切换项目或打开其他任务后，引用预览被清空，不会把上一任务图片带入新请求。
2. 引用其他任务/失效草稿时，发送被拦截并提示重新选择。
3. 引用修改无文本不可发送；商品图加工无原图首轮不可发送。
4. 调整轮请求提示词包含局部修改前缀。
5. 一键重试仍复用失败前快照，不改写成“重试生成”。
6. 自动化：现有 suite + 导航清引用 / 引用归属相关静态断言通过。
