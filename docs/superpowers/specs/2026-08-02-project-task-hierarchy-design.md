# 店铺项目 → 任务记录层级（A · 轻量）

## 目标

明确信息架构：**店铺项目（容器）→ 本项目任务（工作流）**，同时避免项目区视觉过重。

## 方案

采用 **A · 轻量**：

1. 工作台左栏顶部增加单行「当前店铺」上下文（名称 ▾ + 管理），无蓝底大卡片、无平台/任务数副文案。
2. 其下为「本项目任务」标题、新建、筛选与任务列表（视觉主角）。
3. 顶栏移除项目切换器，避免双入口。
4. 工作台左下脚仅保留「提示词管理」「素材库」；「管理」进入店铺项目页。
5. 中间对话 / 右侧画布不变。

## 非目标

- 不改为方案 C（项目首页门槛）。
- 不加重项目卡（初稿蓝底卡废弃）。
